# 決策紀錄與 spec 修正

原始 spec：`taiwan_solar_grid_bottleneck_spec.md`（2026-10-11 草稿，未修改）。本檔記錄之後的決定，以及資料審計後與 spec 不同之處。

## 2026-10-11 產品決定

| 問題 | 決定 | 影響 |
|---|---|---|
| 對象 | 對外發布 | 證據標示、授權顯名、存檔與方法頁都是 v0 必要項目 |
| 範圍 | 守在 spec 的電網範圍 | 不擴及土地、漁電、核准量；只做電網相關資料 |
| 核心需求 | 一目瞭然看現況，資料可引用 | 首屏是現況（數字卡＋地圖）；每個數字附日期、來源、存檔雜湊；固定連結；可複製引用 |
| 部署 | GitHub Pages | 純靜態網站；不用 PostGIS／PMTiles（一縣 3.6 萬點不需要） |

「可引用」需要存檔：台電更新時會覆寫同一網址，只連到台電的引用會失效。所以 v0 先建存檔，引用一律指向本站存檔版本與 SHA-256。

## 資料審計結果：與 spec 不同之處

詳細數字見 `docs/audit/S02_capacity_audit.md`（程式產生）。

### S01／S02 可併網容量

- **檔案日期**：spec 依平臺詮釋資料寫 2024-07；實際 ZIP 內容為 **2026-04**（容量表 2026-04-14、點位表 2026-04-27）。
- **結構**：spec 假設一張表含 `FEEDER/CAPACITY/ROWNUM/X/Y`；實際是**兩張表**：`*_capacity.csv`（饋線、容量 kW）與 `*_tr_feeder.csv`（變壓器座標、所屬饋線）。
  - 容量以**饋線**為單位；變壓器點位沒有容量。spec §8.2「同饋線多點語意」與 §10.3「重複容量」的疑慮因此有答案：點位不可加總，但每條饋線的值本身不重複。
- **S01 與 S02**：兩個有共同日期的版本中，全國檔內的雲林 CSV 與雲林檔**逐位元組相同**。v0 以 S02 為主，S01 只做交叉檢查。
- **更新頻率**：平臺標示每 6 個月；已取得版本為 2024-01、2025-03、2026-04，約一年一版。
- **座標系統**：確認為 TWD67 二度分帶。**陷阱**：PROJ 對 EPSG:3828 的預設轉換只做概略偏移，沒有基準轉換，點位會偏約 850 公尺、上百點落入海中。改用 towgs84 基準轉換後，0 點落在陸域外；與內政部四參數公式相差不到 4 公尺。
- **上限值**：最新版有 16 條饋線剛好是 11,000 kW，疑似上限，待確認。
- **饋線代號穩定性**：相鄰版本共同代號 334／336 條，可作為未來跨版比較的基礎（仍需確認計算條件一致）。
- **位置表有、雲林容量表沒有的變壓器**（最新版 1,453 具，2026-10-11 查明）分三種：
  - 鄰縣饋線 9 條（25 具）：代號開頭 J／A，容量在全國檔的嘉義、南投容量表。v0.1.1 起從**同日**全國檔補值，資訊卡、CSV 標示來源，引用改指 S01 存檔。
  - 雲林代號但兩表皆無 11 條（1,406 具，如崙背麥寮的 XI31–XI35）：標「台電未列容量」，列入待確認。
  - 所屬饋線寫「無」22 具：標「未標饋線」。
- **饋線代號不保證全國唯一**：2025-04 全國檔有 6 個代號在兩縣數值不同（如 CV31 基隆／新北）。跨縣補值只在各縣數值一致時採用。
- **用語**：「無容量列」「點位」對一般讀者不清楚（使用者回饋），改為「台電未列容量」「變壓器」；資料表名稱用「變壓器位置表」。
- **兩種統計口徑分開**：數字卡片與鄉鎮表＝雲林容量表（343 條）；圖例＝地圖上畫出的饋線與變壓器（344 條，含鄰縣、不含無位置者）。

### S03 FGIS

- FGIS 以「六級六色」顯示，但級距只出現在伺服器端圖磚，沒有文字公開。v0 用本專案固定級距（0／<1／1–3／3–6／≥6 MW），並明確標示「非 FGIS 六級」。
- FGIS 前端把負值顯示成 0（目前 S02 沒有負值）。

### S04 立法院等待併網數字

全部數字與原文相符（`data/curated/README.md`），但有兩處要修改用語：
- **不用「全臺」**：表2只列 7 個區處，原文沒說明其他區處是零還是未列。網站寫「表列 7 個區處」。
- 「超過一年者占案件 77.20%、容量 81.02%」是**推算值**，原文只寫「逾七成五」。網站不使用這兩個數字。
- 114 年度報告有同類表格，但範圍是全部再生能源、11 個區處，口徑不同，不能直接接成時間序列（影響 H2）。

### 地圖視覺

- 公布為 0 的饋線占條數 28.3%，但占變壓器點位 52.9%（多為長饋線）。地圖按點著色，橘色面積自然大於條數比例。處理方式：
  - 不讓任何級距畫在最上層；
  - 圖例同時列條數與點位占比，並附一句說明。
- 不用紅色（spec §13.2、附錄 B）。

## 2026-10-12 呈現調整

- **雜湊值退到後台**：使用者擔心一般讀者看到 64 碼雜湊會困惑。保留雜湊（spec §17.1 要求，也是回應「是否改過台電數字」的依據），但首頁、資訊卡、引用文字只寫存檔版本名稱（如 S02-2026-04-27）；雜湊只出現在方法頁存檔表（標為「檔案指紋」並附白話說明）、CSV 檔頭、審計報告與 manifest。
- **方法頁加「常見問題」**（第 2 節）：與台電 FGIS 的差別、與 kiang 地圖的差別、為何只做雲林、公布為 0 的意義、數字對不上時以誰為準、檔案指紋是什麼。首頁導覽加「常見問題」連結。
- **致謝 kiang**（江明宗）：2016 年起的台電可併網容量地圖是先行者（MIT 授權，保存 2016–2021 歷史版本）。比對其程式：座標轉換正確；容量表未列的饋線以 0 呈現；變壓器同色、點選看容量；資料最後更新 2021-09。

## 2026-10-12 更新排程

- **台電來源每週檢查**（原為每月）。理由：台電覆寫同一網址，漏掉一版即永久遺失；宣稱半年一更、實際約一年，但 2026-10 前後可能有新版。台電伺服器支援條件式請求（實測 ETag／Last-Modified 皆回 304、0 bytes），每週檢查幾乎沒有成本。
- **存檔與上線分開**：新版原始檔立即存到 main；網站只用 `published.json` 核准過的版本；新版以 PR 送審（附 `summarize_change.py` 摘要與異常警示），合併即上線。使用者選擇人工審核而非全自動上線。
- **Wayback 獨立備份**：發現新版時自動請 Wayback 另存。2026-10-11 補存了當時上線版（S02 `20261011173228`、S01 `20261011173235`），下載比對與本站存檔逐位元組相同。
- S12 鄉鎮界線網址含版本日期，改為每 90 天比對 data.gov.tw 的下載網址並提醒；S04 立法院報告每年 9 月以 issue 提醒人工處理。
- 網站超過 45 天未成功檢查即顯示逾期提醒（spec §15.4）。
- 推上 GitHub 前，以本機 Claude Code 排程每週一 09:00 執行檢查（只存檔與通知，不 commit、不核准）。
- 審核摘要首次試跑即發現：XU27、XU29 在 2025-03 版容量表仍有數值，2026-04 版才消失（變成「台電未列容量」），是追查成因的線索。

## 2026-10-12 全國比較（擴大的第一階段）

- 首頁新增「雲林在全國的位置」：各縣市公布為 0 的饋線比例（S01 同日全國檔，口徑一致）與各區處等待併網（S04），兩表分開並註明不可相加或換算、比例高不等於「最缺電網」。
- 查證台電全國檔的地理範圍：把各檔變壓器套到內政部縣市界——CHIAYI＝嘉義縣 89.6%＋嘉義市 10.3%，HSINCHU＝新竹縣 76.1%＋新竹市 23.7%，其餘 ≥99.8% 對應單一縣市；澎湖、金門、連江不在檔案中。順帶確認 TWD67 轉換在全國都成立（為擴大鋪路）。
- 新增來源 S14（立法院 114 年度報告表4），只取區處轄區欄；新營與台南區處都寫「台南市」。新增 `--archive-manual` 供人工來源一次性存檔。
- 結果：公布為 0 的比例，屏東縣 39.8%、嘉義縣市 29.6% 高於雲林縣 28.3%；等待併網則雲林最高、屏東次之。第二階段（加入屏東地圖）待夥伴回饋後再做。
- 修正：PDF 來源沒有 ZIP 成員，pandas 產生的 NaN 被寫進 summary.json，使整頁無法載入；改填空字串，並以 `allow_nan=False` 讓類似問題在建置時就失敗。

## v0 範圍與後續

**v0 已完成**：S02 存檔（3 版）＋S01／S12／S04 存檔、座標驗證、饋線現況地圖、鄉鎮組成表、饋線清單、區處等待資訊列、引用功能、方法頁、程式產生的審計報告。

**後續（建議順序）**：
1. 共同升壓站與先行施作工程（S06、S07）：PDF 擷取，人工核對後放進 `data/curated/`。
2. 69kV／161kV 變電所容量（S08）：分層顯示，不與配電相加。
3. 跨版比較：先確認計算條件跨版一致，再開啟差值；評估納入 kiang 快照。
4. 個案敘事：可沿用 `taiwan-energy/deep-dives/D6_雲林光電為何變慢.md` 的證據。
5. 五地區比較（S01 已有全國資料）。

**不做**（與 spec 一致）：重建 FGIS、批次擷取需驗證碼的排隊查詢、把區處等待數字下推到鄉鎮或饋線。
